# 青岚一中校园网 · 离线镜像（伪系统解谜游戏）

致敬《昆水一中校园网》《邺山彼处》的「伪系统 / 伪文档」解谜类型。你闯入一所已停办中学的
校园网离线镜像，靠读论坛、翻文件、解密码、看影像，拼出学生 **苏黎** 留下的真相。

纯前端、零后端、零联网，`file://` 双击即玩；也可打包成 Windows / macOS 安装包。

---

## 怎么运行

- **直接玩**：用浏览器打开 `index.html`（或双击 `启动.command` / `启动.bat`）。
- **打包安装包**（需各自系统各跑一次，Electron 硬限制）：
  - macOS：`npm run dist:mac` → 产出 `dist/青岚OS-*.dmg`
  - Windows：`npm run dist:win` → 产出 `dist/青岚OS-*.exe`
  - 需先 `npm install`。

> 说明：影像（🎬 影像）用的是本地 `assets/videos/*.mp4` 相对路径。用 Electron 安装包或本地
> 静态服务器打开最稳；极少数浏览器在 `file://` 下会拦截本地视频，遇到时改用打包版即可。

## 核心玩法

- **伪系统桌面**：开机 → 多账号登录（访客 / 学生 suli / 管理员 admin / root，四级权限逐级解锁不同内容）→ 一个能 `ls / cd / cat / grep` 的真实虚拟文件系统（含隐藏目录、回收站、权限位）。
- **可敲命令的终端**：`decode` / `encode` 真能编解码（base64 / hex / rot13 / reverse / 维吉尼亚）。
- **图形界面**：💬 论坛 / ✉️ 邮件 / 🖼️ 相册 / 🎬 影像 / 👁 岚，与终端读的是**同一套数据**。
- **v5 套娃层（游戏内继续「套娃」）**：🌐 官网（带站内搜索的伪校园门户 + 需登录的伪教务系统）/ 💬 青岚聊（带加密消息的伪聊天 App）/ 🗺️ 地图（点地点看监控日志）/ 🕒 时间线 / 🧩 推理板。它们**本身就是解谜入口**，且互相牵引（ARG 跨媒介手法）：四枚「印记」分别藏在官网 / 聊天 / 相册 / 地图，集齐拼成守门人密语「青岚不灭」。
- **会说话的幽灵「岚」**：苏黎留在系统里的残响，**v9 起可双向对话**——终端 `talk [问题]` 或直接在她窗口输入框问「下一步怎么走 / 王浩是谁 / 教务处怎么回事」，她按你的真实进度回应、带你往前推，不再只是一句句固定广播。
- **多层结局**：交出去 / 让它睡着 / 集齐四碎片「守门人」/ root 连错 3 次「系统锁定」/ 真·守门人（青岚不灭）/ **v6 新增「最终结论」分支结局**——系统性真相 / 你只看到第一层 / 你抓错了人 / 真相之下（终极）/ **v7 新增「还差一步」**（解到第二层自白却没做矛盾指认，终极结局的门槛提示）。不同结论通向不同结局，推理的落点决定你看到哪一层真相；**终极结局「真相之下」需同时解开二阶自白并做完矛盾指认**。

初次进入会弹使用说明；随时可点顶部「？帮助」重看。卡住时终端输入 `hint` 给当前阶段提示，
`objective` 看当前目标与线索路标。

## 加深后的推理链（v5）

设计原则：**每阶有明确路标（去访问哪），但到了地方要自己推导，不是直给；v5 更把推理从「单线解密」升级为「跨媒介交叉 + 多重验证」。**

1. **guest → student（照片 EXIF + base64）**
   `cat notice.txt` → `open photos` 翻照片，找到 EXIF `Comment` 里那串 base64 → `decode b64` 得到 `suli` 账号与口令。

2. **student → admin（维吉尼亚 + 名字倒序 hex）**
   - `cat note.enc` 是维吉尼亚密文；密钥得**自己从校名推导**——论坛密码学社给的是谜面「校名完整拼音」，玩家要把「青岚」拼成 `QINGLAN`。
   - 解密便签后按提示：去 `diary_1` 找名字 → **倒序 + hex**。`encode hex ilus` 直接算出 `696c7573`（admin 口令）。

3. **admin → root（三段各需解码 + 组合推理）**
   - 回收站 `vault_fragment`（base64）→ `q1ng`
   - 管理员邮件草稿（rot13）→ `lan_`
   - 管理板碎片 C = **苏黎「最后在线」年份**：要去 `/var/log/auth.log` 推理，别和「体育馆事件」那年（2022）搞混 → `2023`
   - 拼成 `q1nglan_2023`。⚠ 旧密钥 `QL_ROOT_1997` 是陷阱。

4. **root → 真相 + 终局推理（证据 / 证人 / 日志 三者交叉）**
   - `/root/truth` 读 `evidence.txt`（7 个被改分的人）、`witness.md`（证人指认「墨渍+跛脚」的陈宇）、再去 `auth.log` 找 `2022.12.24` 当晚在线的人。
   - **三者交叉**：当晚在线只有 `chenyu / liewen / wanghao`，与证人描述唯一重合的是 **陈宇 = chenyu**——把那一晚钉死。
   - 然后在对话里抉择结局。

5. **v5 新增 · 推理机制**
   - **跨媒介元谜题「青岚不灭」**：官网内部系统页脚（b64 `6Z2S`→青）/ 青岚聊匿名X（`5bKa`→岚）/ 相册天台照增强（→不）/ 地图监控室日志（hex `e781ad`→灭），四印记按 网→聊→图→地 连读 = 「青岚不灭」。在 🧩推理板 或终端 `submit 青岚不灭` 提交，解锁守门人真章 `legacy.txt` 与真·守门人结局。
   - **时间线重建**：🕒时间线 在 root 后开放，把 **12 件事**排成一条线（v6 扩写），排对才显现「转折那一晚 2022.12.24」。⚠ v6 埋了「12.24 篡改夜」与「06.17 离校夜（苏黎最后在线）」两件事的陷阱，玩家得分清。
   - **身份视角切换**：同一线索在不同权限下显示不同内容——官网内部教务系统有 学生/管理员/root 三套对照（原始分 vs 改后分 vs 操作记录）；论坛管理板仅管理员可见。
   - **推理板 / 假设验证（三阶段）**：🧩推理板 root 后开放，要求 **6 组「结论 + 支撑证据」**，选完点「核对」——系统只告诉你钉对几组，绝不提示哪组错（参考 Obra Dinn「三连确认、绝不单点剧透」，杜绝试错、逼你真推理）；全对解锁侦探报告 `board_report.txt`；随后浮现「⚖️ 最终结论」三连判断（决定你看见第几层真相）；再其下是 **v7 新增「🔫 矛盾指认」**——三句证词全部选择后再批量核对，只回报击穿数量，三句全破才解锁终极结局。
- **📓 线索笔记本（顶栏「线索」/ 岚快捷 / `open ledger`）**：参考 Blue Prince / Obra Dinn 的「游戏内线索本」，把玩家读到的文件、聊天自白、影像、对质进度**聚合到一处**，按「物证 / 言证 / 系统记录 / 元叙事」分类，方便交叉比对。未解锁的只给「去哪找」的提示，不剧透内容。
- **调查加厚支线**：苏黎导出的 `export_scores.csv` 与管理员缓存 `score_wall_archive.txt` 可做「公示墙 vs 导出表」复核；官网搜索 `撤回 / 修订 / 处分` 可挖到公告修订记录。它们只提供异常事实，不直接替你下结论。
- **人物 / 地点 / 发现历史**：📓线索笔记本新增人物档案、线索标签和发现历史；🗺️地图地点会显示已解锁的关联人物、证据和影像，方便回看推理路径。

6. **元谜题：四碎片组字（隐藏结局）**
   4 块 lore 碎片各藏一个印记（记 / 得 / 真 / 相），集齐按 1→4 读出「记得真相」，解锁隐藏结局「守门人」。与「青岚不灭」是两条独立隐藏线。

7. **照片 hex 隐写（强化概念）**
   第 5 张 `未命名_加密.jpg`（需 level 1）EXIF 是十六进制 `494c5553`：`decode hex` → `ILUS` → 逆序 → `SULI`，呼应 admin 那道「名字倒序」关卡。

## v6 加厚：多层悬疑 + 最终结论 + 元谜题二阶

v6 的核心目标是**把故事线从「单薄的一条解密链」拧成「多层、有反转、要你自己下判断」的推理**。

### 一、两层案子（表面案 vs 深层案）

- **表面案（替罪羊）**：`2022.12.24` 陈宇（chenyu）在内部教务系统改了 7 人成绩，是档案里最显眼的那笔。大多数玩家会停在这，把「幕后」安给陈宇一个人。
- **深层案（系统性舞弊）**：往深查会发现——**王浩（王老师之子）的分数早在 `2022.09` 就被教务处提前垫高**，比陈宇那笔早了三个月。陈宇只是半年后被王老师逼着搅浑痕迹的替罪羊；真正的系统性源头在**教务处**。
  - 新增证据链：`/home/suli/diary_3.txt`（一层：陈宇替罪、王浩 9 月被垫高）、`/home/admin/notes2.txt`（二层：王浩＝王老师之子、教务处系统性）、`/var/log/jiaowu_op.log`（三层：王浩 2022.09 垫高的操作记录，比陈宇 12.24 更早）、`/root/truth/ledger.txt`（锁「最终结论」：系统性舞弊的核心账本）。

### 二、矛盾证人 + 两夜陷阱（逼玩家交叉验证，而非照单全收）

- **匿名证人 X 的身份反转**：青岚聊里匿名X 自称当晚在体育馆「外面」，但 `auth.log` 显示王浩当晚在馆「内」——而匿名X 高权限下会自己坦白「我是王浩，前面那句在馆外是我撒的」。玩家必须自己甄别证人、且不能全信陈宇也不能全信王浩。
- **「12.24 篡改夜」≠「06.17 离校夜」**：v6 把时间线扩到 12 件，并故意把「苏黎最后在线/离校（06.17）」和「成绩被篡改（12.24）」混在一起当陷阱。排错就过不了时间线。

### 三、最终结论（推理的落点决定结局）

推理板六组「结论 + 支撑证据」全对后，下方立刻浮现「⚖️ 最终结论」——三连判断 **执行 / 现场包庇 / 幕后**：

| 你的结论 | 触发的结局 | 含义 |
|---|---|---|
| 执行=陈宇、现场包庇=王老师、幕后=教务处（全对）| **系统性真相** | 看清整条链：陈宇执行、王老师施压/包庇、教务处系统性源头（最优）|
| 把幕后归给王老师个人 | **你只看到了第一层** | 漏了总表——王浩 9 月就被垫高，源头在教务处 |
| 把罪名安在苏黎自己头上 | **你抓错了人** | 她才是追真相的人 |
| 先解锁元谜题二阶（见下）→ 真相之下 | **真相之下（终极）** | 苏黎真正自白的延伸终局 |

定案后 `ledger.txt` 解封，🎬 影像 自动放出 `systemic_truth` / `surface` / `wrong` / `deep_truth` 对应片段。

### 四、元谜题二阶（中文维吉尼亚）

v5 的维吉尼亚只支持拉丁字母；v6 升级 `crypto.js` 的 `vigenere` **支持中文（CJK U+4E00–U+9FFF 码点偏移，可逆）**，且做了**拉丁向后兼容**（既有拉丁密文仍能解）。

守门人真章 `legacy.txt` 里藏着第二层：一段维吉尼亚密文，密钥＝「青岚不灭」拼音 **`QINGLANBUMIE`**。在终端跑：

```
decode vig QINGLANBUMIE <那串密文>
```

解开即解锁 `deepUnlocked` 与终极结局「真相之下」——这是苏黎真正的自白。

### 五、v6 新增内容一览

- **新文件**：`diary_3.txt` / `notes2.txt` / `jiaowu_op.log` / `ledger.txt`（锁「最终结论」）。
- **新台词**：岚增加 `onMeta` / `onVerdict` / `onSystemic` / `onDeep` 阶段语；匿名X 高权限反转消息。
- **时间线 6 → 12 件**，含两夜陷阱与转折标注。
- **推理板 4 → 6 题**，并升级为「结论 + 支撑证据」双层核对 + 最终结论三连分支。
- **结局 +4**：系统性真相 / 你只看到第一层 / 你抓错了人 / 真相之下（终极），共 9 种结局形态。
- **🎬 影像 +4 触发**：`diary3_read`（读日记三）、`ledger_reveal`（定案）、`systemic_truth`（系统性真相）、`deep_truth`（真相之下）。

## v7 加厚：矛盾指认（参考经典解谜游戏的「主动对质」）

v6 已经把「案子」拧成了多层、有反转；但推理仍偏「被动读证据 → 选答案」。v7 补上**主动反驳**的一环——参考三款标杆：

- **《 return of the obra dinn 》**：证据从不自明，玩家要自己判断「哪条记录驳倒了哪句口供」（言证 vs 物证）。
- **《 danganronpa 》**：辩论里把「真相子弹」打在矛盾点上，戳穿说谎者。
- **《 her story 》**：同一事件的多份证词，要交叉检索才能拼出真相。

### 机制：🔫 矛盾指认

六组证据链全对、浮现「最终结论」之后，推理板最下方再出现 **「🔫 矛盾指认」** 区块。给出三句分别来自不同视角/界面的证词，玩家先给**每一句**选择一条能戳穿它的记录，再统一点「对质核对」：

| # | 证词（谁说的） | 戳穿它的证据 | 出处界面 |
|---|--------------|-------------|---------|
| 1 | 陈宇（监控独白）：「那晚就我一个人进了体育馆，没人知道。」 | `auth.log`：王浩 2022.12.24 22:05 体育馆内登录 | 终端 / `/var/log/auth.log` |
| 2 | 匿名X（对外宣称）：「我的分数跟这事无关，都是陈宇 12.24 之后才乱起来的。」 | `jiaowu_op.log`：王浩 2022.09.12 被提前垫高（早于陈宇 12.24） | root / `/var/log/jiaowu_op.log` |
| 3 | 某官方通报 / 王老师口径：「就是个学生一时糊涂，跟老师、跟制度没关系。」 | 李老师聊天自白：「是我让王老师去拦人的」 | 青岚聊（高权限） |

核对只提示「击穿 N / 3 句」，不剧透哪句错；三句**全破**才置 `contradictionDone`，并展示三条解释，触发：
- 岚说 `onContra`：「你把三句证词，一句句戳穿了……这一晚的真相，再也藏不住了。」
- 自动放出影像 **「矛盾 · 崩塌」**（三句谎言在同一块屏幕上同时碎掉）。
- **门槛抬高**：终极结局「真相之下」现要求 `deepUnlocked && contradictionDone`——既解开第二层自白，又把谎言对质击穿，才配得上「看得更深」。只差一步时菜单显示「🌌 真相之下（还差矛盾指认）」，点进去是 `deep_locked` 结局（提示回去做完指认）。

### 设计意图
- **把「看穿谎言」做成操作，而不只是文字**：玩家必须真正从各界面交叉比对、一次性提交自己的对质判断（Obra Dinn 原则）。
- **每条矛盾来自不同界面**：auth.log / jiaowu_op.log / 聊天——强迫玩家在「套娃界面」之间路由（router 原则），而不是在一个页面里读完。
- **对质是终极结局的前置**：呼应「守门人守的不只是密码，是对质本身」。

## v8 加厚：收集玩家好评点，落地两个标杆机制

参考 Obra Dinn / Danganronpa / Her Story / 13 Sentinels / Blue Prince / Zero Escape 的真实好评，提炼出玩家最夸的 6 个设计点，本轮落地其中两个最契合、且风险可控的：

| 好评点（来自真实评测） | 代表游戏 | 本轮落地 |
|---|---|---|
| 「你真的在侦查，游戏不预设解法、不手把手」 | Obra Dinn / Her Story | 推理板改为「不剧透式核对」 |
| 「三连确认、绝不单点剧透，杜绝试错」 | Obra Dinn（头号好评） | 同上：选完才核对，只报答对题数 |
| 「游戏内线索笔记本，不用拿纸笔也能交叉比对」 | Blue Prince / Obra Dinn ledger | 新增 📓 线索笔记本 |
| 「多解 / 不同突破口」 | Obra Dinn | （预留：后续可让 6 题有替代证径） |
| 「非线性重语境化：前面的背景后面才成关键」 | 13 Sentinels / Obra Dinn | 已有时间线 / 闪回铺垫 |
| 「元叙事 / 第四面墙」 | Zero Escape / There Is No Game | 岚（ghost）已具元叙事，v8 加 onLedger 回应玩家收集行为 |

### 机制一：🧩 推理板「不剧透式核对」（Obra Dinn 头号好评）
原版每题点一下立即标红/标绿，等于系统在替你试错。改为：
- 每题都要同时选择**结论**和**支撑证据**；
- 六组选完点「核对」，系统**只回报「你钉对了 N / 6 组证据链」**，**不告诉你哪组错**；
- 只有结论和证据都全对，才解锁侦探报告与最终结论。
这样玩家必须靠自己在各界面交叉验证来推翻自己，而不是靠点错提示蒙答案——正是 Obra Dinn 被狂夸的「尊重智商、你真的在侦探」。

### 机制二：📓 线索笔记本（Blue Prince / Obra Dinn ledger）
顶栏新增「📓 线索」按钮（岚快捷链接、`open ledger` 也可打开）。它把玩家**已发现的碎片**全部聚合：
- 按 **物证 / 言证 / 系统记录 / 元叙事** 四色分类；
- 已解锁的显示来源 + 一句话摘要；**未解锁的只给「去哪找」的提示，绝不剧透内容**（公平性原则）；
- 底部附「🔫 矛盾指认进度」，随时看自己对质到哪了。
岚会在你第一次翻开笔记本时说 `onLedger`——「侦探不是记住答案的人，是知道去哪翻证据的人」。

## v9 加厚：让「岚」变聪明（干掉人机感）

v8 之前，岚是一台「事件播报器」：每个事件触发一句固定台词，从不回应玩家，也不管你到底读到了哪。玩家最直观的感受就是**人机感重**。v9 把她从「广播喇叭」改造成「会根据你进度对话的残响」，套用 ardot-design-router 的思路——**岚是一个按玩家真实状态路由回应的 dispatcher**：

1. **上下文感知台词**：`ghost` 的每句事件台词支持三种形态——字符串（原样）/ 数组（随机抽一条，重玩有变化）/ **函数 `(ctx) ⇒ 台词`**。`ctx` 是当前进度快照（`level`、是否读过 `auth.log`/`jiaowu_op.log`/`diary_3`/`notes2`…、`meta`/`deep`/`contra`/`verdict`）。例如 `onContra` 在你已读 `jiaowu_op.log` 时会**主动多提一句「09.12 那笔垫高」**；`onVerdict` 按你定的结论（surface/wrong/systemic）说不同的话。她开始「记得你看到了什么」。
2. **真正的双向对话**：岚窗口底部加了输入框；终端 `talk [问题]` 也能直接问。你问「下一步怎么走」「王浩是谁」「教务处怎么回事」，她按关键词路由到对应主题，且**每条回应都结合你的真实进度**——没读 diary_3 时她会催你去读，读过了才讲替罪羊的深层。
3. **进度感知指路 `nudgeReply`**：当你问「卡住了」或「下一步」，岚不再给通用提示，而是算出你**最近一个还没探索的关键缺口**（访客→相册 base64；有账号没读 diary_3→去读；没读 jiaowu_op.log→点出 09.12 更早的日期……），像真侦探在带你往前推。
4. **性格与变化**：台词加了少量随机变体（重玩不每次一模一样），语气是苏黎残响的「冷、护着真相、烦造假」——不是客服机器人。

> 设计意图：把「会说话的 ghost」从装饰变成**可交互的侦查伙伴**，是去掉人机感最直接的办法——她不再只对你广播，而是**回应你、记得你、带你走**。

## 影像档案（AI 生成 · 解到即自动放出）

顶部 🎬 影像 不再是「按权限等级手动翻看」，而是**解到某一处、对应影像自己弹出来播放**。每段绑定一个 `trigger` 解锁条件；没解到的会显示解锁条件供你追踪，已解出的可在影像列表里回看。

## 📦 发行与部署

本游戏是**纯静态前端**：零后端、零联网、无需构建步骤。三种发行方式任选其一。

### 1. GitHub Pages 在线托管（推荐 · 零安装即玩）

1. 将本仓库推送到 GitHub（步骤见下方）。
2. 仓库 **Settings → Pages → Source** 选 `main` 分支、`/ (root)` 目录 → **Save**。
3. 等待约 1 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/` 即可游玩。
   - 全站使用相对路径，子路径托管（`/仓库名/`）也能正常加载资源与视频。
   - 通过 GitHub 自带的 HTTPS 提供，影像（MP4）播放无 `file://` 的浏览器限制。

### 2. 直接下载即玩（zip）

在 GitHub 仓库 `Code → Download ZIP`，或 Release 里提供打包好的 zip；解压后双击 `index.html`
（或 `启动.command` / `启动.bat`）。无需任何依赖。

### 3. 桌面安装包（Windows / macOS）

见上方「怎么运行」的打包步骤：本地 `npm install` 后 `npm run dist:mac` / `npm run dist:win`
（Electron 硬限制：两个平台需各自打包一次）。

### 上传到 GitHub（命令行）

```bash
cd qinglan-campus-net
git init
git add .              # .gitignore 已排除 node_modules / dist / .DS_Store / .workbuddy
git commit -m "青岚一中校园网 v1.0.0 发布"
git branch -M main
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

> 也可不跑 `git init`：在 GitHub 网页新建空仓库后，直接执行 `git remote add` + `git push`；
> 或直接在 GitHub 网页 `Upload files` 拖拽本目录（注意 `.gitignore` 里的项目不要手滑传上去）。
