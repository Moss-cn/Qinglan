# 青岚OS · 一中校园网

> **"你闯入一所已停办中学的校园网离线镜像。从终端到论坛、从日记到影像，所有的真相都藏在系统日志里。"**

---

## 🎮 这是什么

**青岚OS** 是一款**纯网页就能玩的离线解谜游戏**。你扮演一位深夜闯入「青岚一中」校园网镜像的玩家——
在一个伪操作系统里，从 `guest` 访客登录开始，逐步用 **终端命令 + 图形界面 App**，翻找学生 **苏黎** 留下的线索，
拼出一段被校方与系统共同掩盖的真相。

致敬《昆水一中校园网》《邺山彼处》等「伪系统 / 伪文档」类解谜作品。

> ⚠️ **无剧透提醒**：本文档只介绍玩法和系统，**不会**告诉你任何谜底。请在第一次通关后再回来对照。

## 🕹️ 怎么玩

### 方式一 · 直接在浏览器里玩（推荐 · 零安装）

> 游戏是纯前端、无后端、无外部请求，**直接打开就能玩**。

- **网页托管版**：访问 `https://<用户名>.github.io/<仓库名>/` 即可（详见下方「获取方式」）。
- **本地打开**：下载后双击 `index.html`（Chrome / Edge / Firefox 均可）。macOS Safari 因 file:// 限制，请用 `启动.command`。

### 方式二 · 下载桌面版

- Windows：运行安装包 `青岚一中校园网-1.0.0-setup.exe`
- macOS：拖入 `青岚一中校园网.dmg` 里的 `青岚OS.app` 到 Applications

### 方式三 · 本地一键启动

| 系统 | 操作 |
|------|------|
| macOS | 双击 `启动.command`（自动用 Python 启动本地静态服务器并打开浏览器） |
| Windows | 双击 `启动.bat`（同上） |

## 🔑 上手指南（不剧透）

1. 进入游戏后，**先以 `guest` 访客身份**逛一圈，习惯终端命令（输入 `help` 看所有命令）。
2. 多试几个 GUI 应用：💬 论坛 / ✉️ 邮件 / 🖼️ 相册 / 🎬 影像 / 🌐 官网 / 👁️ 岚。
3. 在论坛里读到关键帖子时，留意**时间、地点、人物**——它们往往是密码提示。
4. 影像（视频）只在满足特定条件后才会解锁，**不剧透的方式**触发它们。
5. 推理板 6 题全对后，会开启更深层的真相——但这只是**多条路之一**。
6. 任何时候不知道下一步，可以**和岚说话**——她会读你的进度并给出方向（输入 `talk 你想问的`，或在顶栏点 👁️ 岚）。

> 💡 进度**不保存**。这是设计选择：解谜游戏重玩才有意思。如果想保存某个关键发现，截图或记笔记。

## 💡 常见问题

**Q：触屏 / 手机能用吗？**
A：游戏是桌面伪 OS 设计，**窗口拖拽需要鼠标**，手机体验不完整。建议在电脑上游玩。

**Q：进度会保存吗？**
A：不保存，刷新即重置（解谜重玩设计）。

**Q：游戏会联网吗？**
A：不会。完全离线，无遥测、无后端、无任何外部请求。隐私上你 100% 安全。

**Q：密码忘了怎么办？**
A：所有密码都藏在游戏内的某个文件/帖子/影像里。提示：试试 `cat`、`grep`、`read` 等命令。

**Q：岚是谁？**
A：她不是攻略。她只是一个……住在系统里的角色。去和她对话就知道了。
